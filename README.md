# pict-fight (ピクトファイト)

超軽量・リアルタイム同期型のオンラインマルチプレイヤー・ピクトグラムバトルアクションゲーム。

外部の物理ライブラリやゲームエンジン（Phaser, Matter.js など）を一切使用せず、純粋な **HTML5 Canvas + Vanilla JavaScript（クライアント）** と **Node.js + ws WebSocket（サーバー）** のみで構築された超高速設計です。

---

## 🎮 ゲームシステム & 特徴

### 1. コアバトルシステム
* **ダメージレート制 (Damage Rate)**: 体力ゲージはなく、ダメージ蓄積（％）が上がれば上がるほど、攻撃を受けた際のノックバック飛距離が指数関数的に伸びていきます。
* **バーストゾーン (Blast Zone)**: 画面外（上下左右）の一定領域に吹き飛ばされると撃墜（KO）となり、残機（Stock）を失います。
* **すり抜けプラットフォーム**: 中央のソリッドなメイン足場に加え、下入力をホールドすることで通り抜け可能なすり抜け床が「バトルフィールド構成」で配置されています。
* **ガードとシールドブレイク**: 地上でガード（シールド）を展開し、相手の攻撃や飛び道具を防ぐことができます。ただし、ガードし続けるとシールドが縮小し、耐久値がゼロになると気絶状態（シールドブレイク）になります。

### 2. キャラクタークラス（抽選システム）
対戦参戦時および各ラウンド開始時に、プレイスタイルの異なる2つのキャラクタークラスからランダムに自動選択されます。
* **近接型 (Striker)**: 
  * 射程は短いながら、発生が早く強力な近接打撃攻撃（通常攻撃 / 強チャージ攻撃）を持ちます。強チャージ攻撃（Max Charge Strike）は溜めることで極めて重いノックバックを発生させます。
  * 外見：細身の近接戦闘ピクトグラム。
* **遠隔型 (Blaster)**:
  * 腕がレーザーキャノン銃になっており、光弾（飛び道具）を連射できます。強チャージ（Max Charge Strike）を行うと、巨大なプラズマ弾を射出して遠距離から大ダメージを狙えます。
  * 外見：右腕の先端がブラスターキャノン銃身になった射撃特化ピクトグラム。

### 3. 先進的なビジュアル・UI設計
* **ベクターピクトグラム・アニメーション**: 走る・跳ぶ・攻撃する・やられるなどの姿勢が完全に物理演算と同期したキャンバス線画アニメーションで滑らかに表現されます。
* **視認性の高い「向き」表現**: クライアント側の反転（`scale`）に加え、顔部分の「発光バイザー（視線）」および「足元の移動方向を示す光の矢印（シェブロン）」により、静止中でもキャラの向きが一目で把握可能です。
* **画面外インジケータ**: プレイヤーが画面外へ吹き飛ばされた際、画面端にそのキャラのアイコンと蓄積ダメージがポップアップ表示され、画面外での位置関係が可視化されます。
* **対戦終了（MATCH SET）**: 残機ゼロで脱落（DEFEATED / 観戦モード）となり、最後の1人が決まった時点で勝者発表演出を挟んで自動リスタートします。

### 4. 超軽量アセットレス設計
* **Web Audio API シンセサイザー**: 外部音声ファイル（mp3/wav等）を一切ダウンロードせず、ブラウザ上でリアルタイムにレトロ調シンセサイザーの音波（ジャンプ音、打撃音、爆発音、レーザー射撃音など）を合成再生します。
* **ローカルストレージ連携**: プレイヤーのニックネームはブラウザの `localStorage` に安全に記憶され、次回接続時に自動で入力欄にセットされます。

## ⌨️ 操作方法 (Control Guide)

ゲーム中、**「H」キーを押し続けている（ホールド）間のみ**、画面上にリアルタイムで操作マニュアルがオーバーレイ表示されます。

| キー操作 | アクション |
| :--- | :--- |
| <kbd>←</kbd> <kbd>→</kbd> / <kbd>A</kbd> <kbd.D</kbd> | 左右移動（バイザーと足元の矢印が向いている方向を指示） |
| <kbd>↑</kbd> / <kbd>W</kbd> | ジャンプ / 空中ダブルジャンプ（最大2段まで） |
| <kbd>↓</kbd> / <kbd>S</kbd> | すり抜け足場のすり抜け降下（硬直中以外のみ有効） |
| <kbd>Z</kbd> / <kbd>J</kbd> | 通常攻撃（Striker: 近接パンチ / Blaster: レーザー小弾射撃） |
| <kbd>X</kbd> / <kbd>K</kbd> | 最大溜め強攻撃（長押しでチャージ、離して発動） |
| <kbd>C</kbd> / <kbd>L</kbd> | シールド / ガード（地上時のみ展開可能） |
| <kbd>H (ホールド)</kbd> | 操作マニュアルのオーバーレイ表示 |

## 🛠️ インストール & 起動手順

### 必要な環境
* **Node.js** (v16以上推奨)
* **npm**

### 1. 依存関係のインストール
プロジェクトのルートディレクトリで以下を実行します：
```bash
npm install
```

### 2. サーバーの起動
```bash
npm start
```
起動すると、サーバーはデフォルトでポート `3000` で待機を開始します。

### 3. ブラウザでアクセス
複数人の対戦テストを行う場合、ブラウザの異なるタブやウィンドウ（シークレットウィンドウ等）で以下のURLを開いてください：
```
http://localhost:3000
```
ロビー画面でニックネームを入力し、「Join Match」をクリックするとゲームアリーナに入場します。1人の場合はサンドボックス練習モードとして自由に練習でき、2人以上接続するとオンライン対戦が開始されます。

## 📐 アーキテクチャ設計
* **サーバーサイド物理演算 (`server.js`)**: サーバーが60Hzで各プレイヤーの位置・速度・めり込み・衝突検知・やられノックバック・光弾の軌道処理を1フレームの遅延なく計算し、全クライアントへ完全同期パケットを送信します。
* **クライアント描画 (`public/js/client.js`)**: `requestAnimationFrame` に基づく高精度な描画エンジン。サーバーから送られてくるプレイヤー座標の同期に加え、画面揺れ（Screen Shake）エフェクト、物理パーティクルの減速スライドなどの演出をフロントエンドで個別に走らせることで、ネットワーク上の負荷を最小限に抑えつつ滑らかな打撃感を実現しています。
